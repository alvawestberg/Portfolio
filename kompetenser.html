Skills

During my Information Systems program, I have developed skills in web development, programming and database management. My part-time role in IT systems administration has given me practical experience in user support, troubleshooting and documentation.

Technical Skills

  • HTML – I structure web pages with semantic elements and provide clear labels for form fields.
  • CSS – I design responsive layouts and use typography, colour and spacing to organise information.
  • JavaScript – I develop interactive features, such as controls that show or hide content.
  • Python – I write programs that process user input and use functions to organise the code.
  • SQL – I write queries to retrieve, filter and sort information in relational databases.
  • Web Development – I plan website content and navigation and test whether visitors can use links and forms with a keyboard.
  • IT Systems Administration – I support users, troubleshoot technical issues and document solutions to recurring problems.

Professional Skills

  • Collaboration – In group projects, I help define responsibilities and check that each part of the work fits into the final project.
  • Communication – I adapt my technical explanations to the audience, both when supporting users and when working with project teams.
  • Creativity – I explore different ways to structure a web page and assess which layout makes information easiest to find.
  • Problem-Solving – I investigate possible causes systematically and verify that the solution resolves the issue.
